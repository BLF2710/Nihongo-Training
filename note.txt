!!! IMPORTANT: keys and accounts to set up (nihon-api/.env) !!!
=============================================================
Without these, parts of the site run in a limited mode. Restart the API after editing .env.
[ ] Azure Speech key (pronunciation + fluency): Azure portal > Create a resource > Speech, free F0 tier is enough to start.
    Add AZURE_SPEECH_KEY (Key 1) and AZURE_SPEECH_ENDPOINT (the short-audio recognition URL, see README) to nihon-api/.env
[ ] Anthropic API key (content of free answers, also turns the study assistant into Claude): console.anthropic.com, pay-as-you-go, no free tier.
    Add ANTHROPIC_API_KEY to nihon-api/.env; SPEAKING_GRADER_MODEL=claude-haiku-5-5 is the cheapest option
    (without either key: read-aloud only, checked by text match; restart the API after editing .env, then test one real answer of each kind)
[ ] Gmail for sending emails (password reset, email confirmation): turn on 2-Step Verification, create an app password at
    myaccount.google.com/apppasswords, then add to nihon-api/.env (write @ in the address as %40, app password without spaces):
    SMTP_URL=smtps://your.address%40gmail.com:yourapppassword@smtp.gmail.com:465
    MAIL_FROM=LingoHub <your.address@gmail.com>
    (until then emails are printed in the API's console window; Gmail has a daily limit, so use Brevo/Resend/Mailgun/SES for launch: same SMTP_URL line)

pair). Live updates use server-sent events at GET /api/events; the server only says "something changed" and
